# Citing exohab

If exohab helps your work, please cite it. Each release is archived on
[Zenodo](https://doi.org/10.5281/zenodo.24269967) with a permanent DOI.

| DOI | Use it for |
|---|---|
| [10.5281/zenodo.24269967](https://doi.org/10.5281/zenodo.24269967) | The project as a whole (always resolves to the latest version) |
| [10.5281/zenodo.24269968](https://doi.org/10.5281/zenodo.24269968) | Version 0.2.0 specifically |

```bibtex
@software{sivagnanam_exohab,
  author  = {Sivagnanam, Kailash},
  title   = {exohab: exoplanet habitability toolkit for Python},
  version = {0.2.1},
  year    = {2026},
  doi     = {10.5281/zenodo.24269967},
  url     = {https://doi.org/10.5281/zenodo.24269967},
  license = {MIT}
}
```

The same metadata is in
[`CITATION.cff`](https://github.com/kailash9342/exohab/blob/main/CITATION.cff);
GitHub's "Cite this repository" button reads it.

Please also cite the **original papers** of the metrics you use, listed on
[Science & methods](science.md#references), and acknowledge the NASA
Exoplanet Archive if you use its data (see [Data](guide/data.md#acknowledgement)).
